Note! The source file and the language(s) files must be JSON files containing the same keys.

How does it work?
The source file must contain the original keys along with their icons and %? placeholders (e.g., "menu.singleplayer": "\uDB80\uDC00 %? \uDB80\uDC00§r"). Each language file must contain the same keys, but only with the translated text (without icons or %?). The tool then replaces each %? in the source file with the corresponding translation, while keeping the icons and colors intact. A ZIP file containing a converted JSON file for each language is then generated, ready for download. You can also click "All Languages" to automatically fetch every official Minecraft language file from mcasset.cloud and use them directly.
